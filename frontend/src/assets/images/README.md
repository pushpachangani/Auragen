# AuraGen image assets

These assets are included directly in the project:

- `hero-brain.svg` — cognitive AI network used on the landing page
- `login-robot.svg` — AI assistant used on the sign-in page
- `analytics-orbit.svg` — reusable AI analytics illustration
- `empty-state.svg` — reusable analytics/empty-state illustration
- `landing-login-preview.png` — landing and login screen preview shown on the landing page and README

The SVG illustrations were created specifically for this demo and can be edited in any vector editor.
